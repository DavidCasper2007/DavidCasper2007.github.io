# David Casper portfolio

A static website. Every file in this folder is ready to serve as it is, so no build step is needed to host it.

## What is here

| Path | What it is |
| --- | --- |
| `index.html` | Home page: projects, about, experience, skills, contact |
| `projects/*.html` | One page per project |
| `assets/site.css`, `assets/site.js` | Styles and behaviour (charts, photo lightbox, copy button) |
| `assets/img/`, `assets/video/` | Web-ready photos, drawings and clips |
| `404.html`, `favicon.svg`, `.nojekyll` | Housekeeping for GitHub Pages |

## Hosting on GitHub Pages

1. Put the contents of this folder at the root of a public repository.
2. In the repository, open Settings, then Pages.
3. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. The site appears at `https://<username>.github.io/<repository>/`, or at `https://<username>.github.io/` if the repository is named `<username>.github.io`.

## Editing

Small text changes can be made directly in the HTML files. The pages were generated by a small Python build script that is
kept with the project source rather than in this folder. That script is the better place for larger changes, because it
keeps figure numbers and navigation consistent.
